# IoT26-HW01: LED Blinking

## Project Description
This project controls an LED connected to a Raspberry Pi.
The LED turns on for one second and turns off for one second repeatedly.

## Hardware Components
- Raspberry Pi 5
- LED
- Resistor
- Breadboard
- Jumper wires

## Circuit Connection
- LED positive leg: GPIO 14
- LED negative leg: GND

## Source Code
The Python code uses the gpiozero library.
The LED is connected to GPIO 14 and blinks forever.
